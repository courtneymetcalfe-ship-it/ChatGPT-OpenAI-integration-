# Jungle Beat Crew — an original gorilla music-mixing game for iPhone

A playful rhythm mixer inspired by the *genre* of character-based beat-making games. Everything included here — character designs, generated loops, branding and UI — is original. This is **not** Gorilla Tag, Sprunki or Incredibox, and is not affiliated with their creators.

## What is playable?
- Ten unique musical gorilla-like jungle creatures, each with its own original, looping sound.
- Six available stage positions. Tap a character in the bottom collection to place/remove it; tap an occupied stage position to remove.
- Syncing 112-BPM mixer with play/pause, mute, solo, shuffle, presets and clear-stage controls.
- Animated stage, visual beat bar and responsive iPhone-friendly UI.
- Name, save, load and delete mixes stored **only on-device** (no account, ads, analytics or server).

**Note:** This is an early MVP, not a tested/shippable App Store release. Native build, device audio-sync checks, accessibility review, icon/screenshots, privacy details and App Store review remain.

## Start on a laptop
Node.js >=22 recommended.

```bash
npm install          # generates original WAV files deterministically
npx expo start       # open in a compatible Expo Go app
```

Source audio is regenerated by `npm run audio` and is automatically created on `npm install`. The `assets/audio/*.wav` files are intentionally not committed to source control so sound generation remains reproducible; the downloadable ZIP includes generated sound files.

## Cloud build for Apple

```bash
npm install
npm install -g eas-cli
eas login
eas build:configure
# Provision your Apple developer credentials when prompted
eas build --platform ios --profile preview
# For TestFlight/App Store after validating the preview:
eas build --platform ios --profile production
eas submit --platform ios
```

The iOS bundle ID in `app.json` is a starting value; choose an identifier you control before Apple distribution. EAS needs an Expo account and Apple signing credentials. This repo is **not** linked to your Apple account automatically.

## Technology
Expo SDK 57 / React Native; `expo-audio` with generated PCM loops, React Native SVG and AsyncStorage. The design is portrait-first but scales to larger iPhones and iPads.

## Rights / safety

Do not bundle gameplay artwork, voices, sprites, logos or music from Gorilla Tag, Sprunki or Incredibox without rights.
